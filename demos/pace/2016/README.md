# PACE 2016

From this directory, run `python feedback_vertex_set/solve.py` for the bundled example. Pass an instance path or `-` for standard input. The table uses `--seconds 5` on the listed public inputs.

| Demo | Public input | Measure | Result |
|---|---|---|---:|
| [Feedback vertex set](feedback_vertex_set/solve.py) | [001.graph](https://github.com/ckomus/PACE-fvs/blob/master/public/001.graph) | deleted vertices | 204 |
| [Treewidth](treewidth/solve.py) | [format example](https://pacechallenge.org/2016/treewidth/) | width | 1 |

The treewidth example is the five-vertex path from the format specification. Its optimal width is 1.

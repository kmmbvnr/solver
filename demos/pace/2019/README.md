# PACE 2019

From this directory, run `python hypertree_width/solve.py` for the bundled example. Pass an instance path or `-` for standard input. The table uses `--seconds 5` on the listed public inputs.

| Demo | Public input | Measure | Result |
|---|---|---|---:|
| [Hypertree width](hypertree_width/solve.py) | [htd-exact_001.hgr](https://pacechallenge.org/files/pace2019-htd-exact-public.tar.bz2) | width | 2 |
| [Vertex cover](vertex_cover/solve.py) | [vc-exact_001.gr](https://pacechallenge.org/files/pace2019-vc-exact-public-v2.tar.bz2) | selected vertices | 2606 |

The vertex-cover demo constructs feasible covers for the exact-track instances. The hypertree demo compares a single guarded bag with path decompositions.

[Competition and tracks](https://pacechallenge.org/2019/).

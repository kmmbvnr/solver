# PACE 2018

From this directory, run `python steiner_tree/solve.py` for the bundled example. Pass an instance path or `-` for standard input. The table uses `--seconds 5` on the listed public inputs.

| Demo | Public input | Measure | Result |
|---|---|---|---:|
| [Steiner tree](steiner_tree/solve.py) | [Track1/instance001.gr](https://github.com/PACE-challenge/SteinerTree-PACE-2018-instances) | total edge weight | 687 |

The pipeline compares shortest-path trees rooted at different terminals. It accepts all three input variants and ignores the optional decomposition in Track 2.

[Competition and tracks](https://pacechallenge.org/2018/).

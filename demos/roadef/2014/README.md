# ROADEF/EURO 2014 · Rolling stock management

Run `python solve.py > plan.csv` for the bundled `B1.zip`, or pass another final-format archive. The baseline parks compatible initial trains in available yards for the horizon. It compares parking orders, respects yard capacity and excludes yards with imposed consumption. Arrivals and departures remain uncovered and incur the competition penalty.

Official checker v2.3 accepted **2,555,400** on B1, down from **2,587,400** with no scheduled trains. Overall winner S18 scored **699,749.94** on this instance. To verify, run `java -jar checker.jar B1.zip plan.csv`.

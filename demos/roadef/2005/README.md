# ROADEF 2005 · Car sequencing

Run `python solve.py > sequence.txt` for the bundled public `064_38_2_EP_RAF_ENP_ch2`, or pass a directory containing its four input files. Two seeded swap searches improve the supplied production order. Scoring includes the previous day's tail, the ending ratio windows and the maximum paint batch size.

The input sequence scores **284,650**. The pipeline reached **284,648** in a five-second budget. The evaluator's published candidate scores **13,299**. The Python scorer reproduced both archived scores when given their respective sequences. Lower is better.
